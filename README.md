# RAZ 精读记录工具

用于记录小朋友 RAZ 精读进度、制定阅读计划。

## 已扫描书库

- 当前已扫描 10 个等级：AA / A / B / C / D / E / F / G / H / I
- 共 863 本（解压 J-Z2 后重新扫描会更新）

## 打开方式

推荐用本地 HTTP 服务器打开，这样浏览器才能正常读取 `data/books.json`，并且能直接播放视频。

```bash
cd "/Users/dingke/小竹学习/通用/英语/A1014-RAZ精读视频"
python3 -m http.server 8765
```

然后在浏览器打开：

```
http://localhost:8765/raz-tracker/
```

## 功能

- **书库**：按等级浏览、状态筛选、书名搜索、网格/列表视图。
- **书详情页**：点击书籍进入独立页面，左侧为视频播放器 + 点赞/转发/评论，右侧为记录卡片。
- **视频播放**：支持全屏；播放完整后**自动标记为「已完成」**，并自动累计阅读次数。
- **状态三态**：未读（没开始过播放）/ 进行中（一遍没播放完）/ 已完成（至少播放完一遍）。
- **阅读次数**：完整播放次数自动统计，不可手动修改。
- **掌握度**：人工评级（生疏/一般/熟练/精通）。
- **人工记录**：可手动修改状态、评分、掌握度、开始日期、笔记。
- **完成锁定**：「已完成」只能由视频播放完整自动设置，不能手动勾选。
- **点赞/转发/评论**：每本书下可点赞、转发、发表评论，评论可删除。
- **精读计划**：每日新书任务 + 间隔复习任务（自动按遗忘曲线安排复习，如第 2/7/30 天），完成度自动判定；学习日历打卡；按实际节奏（近 14 天平均）推算本等级与全部完成时间。
- **进度统计**：总进度、完成率、各等级进度条、近期活动。
- **数据管理**：导出/导入 JSON 备份，进度与播放位置保存在浏览器 localStorage。

> 说明：旧数据中的「复习中 / 跳过」状态会在加载时自动归为「未读」。

## 更新书单

解压 J-Z2 的 zip 后，运行：

```bash
cd "/Users/dingke/小竹学习/通用/英语/A1014-RAZ精读视频"
python3 raz-tracker/scan_books.py
```

刷新浏览器即可。

## 文件说明

- `index.html` + `style.css` + `app.js`：书库与统计页面
- `book.html` + `book.js`：书详情页（视频 + 记录卡片）
- `data/books.json`：扫描生成的书单数据
- `scan_books.py`：扫描视频文件生成书单的脚本
